# Matcha Flavoured

> Reworks minecraft's gameplay to benefit slower, less technical players

## Description

![Minecraft Matcha Flavoured - A datapack designed to reward casual players. No more mob grinders, xp farms, or villager torture chambers](https://cdn.modrinth.com/data/cached_images/9fe0e32873c6558ff6c38765b432bdc4da8bc676.png)

Matcha Flavoured is a datapack designed to reward casual and non-technical players who don't enjoy making mob farms, or engaging in the technical aspects of minecraft. The goal being for casual players, who like to play slowly, to be able to gather the same amount of resources technical players do in the same amount of time. 

If you want something chill, use Easy mode, if you'd prefer a challenge, stick to Normal, and if you want to pull your hair out and scream, play on Hard c:

If you enjoy making mob farms, you probably won't enjoy playing this pack

**THERE IS NO OFFICAL WIKI/WEBSITE/SERVER FOR THIS PACK** These people are trying to scam you, don't buy into it

### Some Tips

- Early-game is harder now, remember to use every tool at your disposal
- If you prefer something more relaxed, switch to "Easy" Gamemode. Reload the world, and make sure the chat message say "You are in Easy"
- Stone tools don't exist you go from Wood -> Copper -> Iron etc.
- Go to The End when you're ready, no need to rush, shulkers are now early-game features
- Break Spawners!
  
- **Im stuck in early progression!:** Make sure you check advancements and recipes you CAN'T craft. The first thing you should be doing is making a campfire, wooden hoe, and collecting grass to cook. Then you'll be able to make the mudkiln and continue on the path

- **Accessibility!!!:** You can change/remove textures in the resource pack. But if you're lazy or scared! I made an accessible version of the RP: [Accesible Matcha Flavoured](https://modrinth.com/resourcepack/accesible-matcha-flavoured-rp) **Please read the installation instructions on that page**
- If the true darkness is too dark, go to the DATAPACK Matcha_Flavoured\data\minecraft\dimension_type and follow the instructions. 
- Or use this: [Matcha-Vanilla Flavoured Resource Pack](https://www.planetminecraft.com/texture-pack/matcha-vanilla-flavoured/) 


## Installation
The data and resource pack are bound together, place the same file in the datapack and resourcepack locations and everything should be kosher. 

**IF YOU USE MODRINTH TO LOAD IT:** It wil only install it as a resource pack. Datapacks are not currently supported in the loader since they are per-world and not per-instance. You have to install it into a world manually.

You might not want to put this into a pre-existing world, as items have been shuffled around. If you really would like to anyways, that's fine, but you should probably enable cheats so you can fix where things break-down. 

**If when you reload the game a chat message saying "Matcha Flavoured is now loaded" is displayed, its working, otherwise you've installed something wrong**

- **Im still having trouble!!:** When you create your world make sure you manually add the zipped Matcha_Flavoured file into the datapacks temp folder (Go to "More" tab when creating the new world, click "Datapacks", then "Open Pack Folder" and drag the ziped file into there) Make sure you move it to the right column labeled "Selected". If textures aren't showing up, add the same file to the Resource pack folder.

- **But I already made a world!/Need to add it to a preexisting world!:** Select a world, click the "Edit" option, then "Open World Folder". Select the "datapacks" folder, drag the zipped file into there

**UPDATING** Just replace the zips in BOTH (RP and DP) locations, it will be fine, the only thing that will (should) break are items not stacking with each other, or a tool/trade not being updated, both of which can be fixed in-game with Amnestics and Grindstone villager. If you see something like "item.kleispack.filler" that means you only updated the DP and not the RP (Or I forgot a lang)
