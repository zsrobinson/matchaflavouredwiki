# Page plan

The planned article set, grouped by the area that owns it. Link to any page on this list
freely, even before it exists. Page titles are final: use them exactly, and never invent a
parallel page for a topic that already has one here. Item articles use the item's in-game
`en_us` name; `tools/query.py search <text>` finds it.

Every custom or renamed item already has a generated stub (in `wiki/generated/Main/`).
To write a real article, create `wiki/pages/Main/<Title>.wiki`, which replaces the stub.
